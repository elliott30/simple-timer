# Simple Timer

A lightweight countdown timer Chrome extension built for anyone who needs one — teachers, students, presenters, or anyone running a quick session.

## How it works

Click the extension icon and a new tab opens with a single input field. Type a time and press Enter to start the countdown.

**Accepted formats:**
- `5` — 5 minutes
- `4:30` — 4 minutes 30 seconds
- `1.5` — 90 seconds

The countdown fills the screen in large digits. Pause and resume mid-count, or reset to run it again. When time runs out, the display pulses red.

## Built with

- [Chrome Extensions API (Manifest V3)](https://developer.chrome.com/docs/extensions/mv3/) — extension structure and tab management
- [Pillow](https://python-pillow.org/) — icon generation
- [Claude](https://claude.ai) — built entirely with Claude Code
